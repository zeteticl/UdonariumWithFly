# Udonarium 烏冬ユドナリウム開發日誌

從 fork 最新 [Udonarium with Fly](https://github.com/NanasuNANA/UdonariumWithFly) 到 `hktrpg-main` 為止的功能篇。一篇一個功能，不含修 bug。

本站：https://z01.hktrpg.com/

---

Udonarium烏冬ユドナリウム開發日誌01
舊飛行版停喺 2021，好想跟返最新 With Fly
所以整個 fork 搬去新基底
Angular 20、SkyWay 2023、自架 backend
介面可以切繁／簡／英／日
訪客模式、筆記倉庫、角色卡一鍵擲骰都帶埋過嚟

---

Udonarium烏冬ユドナリウム開發日誌02
跑團時成日拖滑鼠好煩
所以加咗鍵盤操作棋子
選取之後 WASD 移動、Shift＋WASD 轉向
Ctrl＋Z／Y 可以復原重做
仲可以 Ctrl＋左鍵畫路徑，Space 就行過去

Udonarium烏冬ユドナリウム開發日誌03

所以加咗桌面光照同視野
地圖可以全暗、有擋光牆、有燈
角色可以宣告「用邊個嘅眼睛睇」
GM 用場景工具畫牆同放燈

Udonarium烏冬ユドナリウム開發日誌26
入房同斷線成日嚇親人：桌面清空、幽靈房、邀請連結壞咗又冇反應
所以連線同邀請流程再收一輪
進房前保留本機桌面，確認有人有地圖先接上
幽靈房從列表隱藏，唔會踢走已入房嘅人
斷線自動 remesh；token／backend 出事優先重開房，唔默默踢去大廳
邀請連結無論好壞都先凍結畫面；損壞就話你「無效或已損壞」
第二個分頁入房，TOKEN／圖都較易即刻見
