## 五分鐘上手 {#quickstart}

1. 用 **Chrome／Edge** 開啟 https://z01.hktrpg.com/ ，選好語言後開始（或略過）引導教學。  
2. 進入後會自動顯示**大廳**與連線面板（尚未進房時）；設暱稱 → **建立房間**或從大廳加入（建議順便綁定**資料夾備份**）。  
3. 複製 **玩家邀請連結** 私訊給團員。  
4. **地圖** 上傳地圖圖；把角色圖拖進瀏覽器或從 **圖片** 上傳；空白處右鍵新增角色。  
5. 聊天選好 **BCDice 規則**；角色右鍵 →「作為我的角色」／需要時開聊天面板。  
6. **結束前**：確認資料夾已寫入，或再 **下載一份 ZIP**。

> 想自己練手：開兩個視窗（一般＋無痕）互相進同一房。

## 這是什麼、請先記住的三件事 {#about}

**Udonarium（烏冬）** 是在瀏覽器裡跑的桌遊／TRPG 虛擬桌面。本站是 [HKTRPG](https://www.hktrpg.com/) 改造版（基底為 [Udonarium with Fly](https://github.com/NanasuNANA/UdonariumWithFly)）：多語介面、光照／視野、戰鬥追蹤、鍵盤操作、資料夾備份、引導教學等。

### 必記三點 {#about-three}

1. **資料主要在玩家之間互傳（P2P）**  
   伺服器協助連線，但**不會**長期保管棋子、圖片、聊天紀錄。房間清空、全員離線後，線上桌面就沒了。

2. **離開前一定要存檔**  
   「下載 ZIP」或「資料夾備份」。不存就會像煙火一樣消失。

3. **建議桌面版 Google Chrome（HTTPS）**  
   資料夾備份依賴 File System Access API；手機／Safari 功能可能不完整。

## 環境與建議 {#environment}

| 項目 | 建議 |
|------|------|
| 瀏覽器 | 桌面 **Chrome** 或 **Edge** |
| 連線 | 穩定網路；同房人數多時頻寬與 CPU 負擔會升高 |
| 測試 | 一人測試可開兩個瀏覽器視窗（或一般＋無痕）互相進房 |

介面語言可在歡迎頁、連線面板或 **設定\*** 切換：繁中／简中／English／日本語（會記住）。

## 第一次進入：引導教學與滑過提示 {#first-run}

### 引導教學（Guided tour） {#guided-tour}

首次使用會出現歡迎畫面，可先選語言，再「開始」或「略過」。

| 章節 | 內容 |
|------|------|
| 第一章 | 房間機制、資料夾備份、ZIP |
| 第二章 | 左側各選單（含預設場面、劇本文字；請實際打開一次） |
| 第三章 | 地圖平移／滾輪／右鍵新增物件 |
| 第四章 | 選取、WASD、刪除、剪貼簿、復原、路徑移動、Ping |

- 高亮處需完成指定操作才會前進（也可略過本章／全部）。  
- 之後可在 **設定\*** →「重新引導教學」重播。  
- 右鍵選單也有「操作說明」等入口。

### 滑過教學提示（Hover tips） {#hover-tips}

導覽結束後，滑過左側選單或聊天工具列按鈕，會跳出簡短說明 BOX（**僅桌面**；手機／平板不會顯示，以免點選後提示卡在地圖上）。  
可在 **設定\*** 開關「滑過顯示教學」；引導進行中會暫時關閉，避免擋畫面。

## 畫面與左側選單總覽 {#ui-overview}

典型畫面：中央是 2.5D 地圖；左側是功能選單；可拖曳開啟多個面板（連線、聊天、倉庫等）。

| 選單 | 用途 |
|------|------|
| **連線** | 暱稱、開房／大廳（開站未進房會自動顯示）、身份、邀請連結、ZIP、資料夾備份、同桌玩家 |
| **聊天** | 多頻道、BCDice、聊天面板（指令板）、本機工具列（可同時開多個聊天視窗；大小／位置會記住） |
| **地圖** | 地圖圖、格線、黑暗、天氣、視野（FoW） |
| **圖片** | 共用圖庫（也可把檔案拖進瀏覽器） |
| **音樂** | 共用多軌 BGM／環境音；曲庫可依資料夾管理；ZIP／備份可選是否含音樂 |
| **工具箱** | 天氣／日夜、Cut-in、骰表、視角、ZIP／資料夾備份等快捷 |
| **戰鬥** | 先攻與回合追蹤 |
| **場景工具** | 燈光、牆壁、繪圖、文字（通常 GM） |
| **預設場面** | 儲存／一鍵還原 token 位置、桌面氣氛與多軌 BGM（縮圖預覽；可「套用（保留棋子）」；可附切場文字） |
| **劇本文字** | 預寫旁白／劇本，全文或選取片段一鍵送目前聊天分頁 |
| **倉庫** | 角色：桌面／公用／私人／回收區 |
| **筆記** | 共用筆記倉庫（見 [筆記](#notes)） |
| **設定\*** | 僅本機：格線顯示、吸附、音效、立繪、語系、教學；**視點重置**／**清空桌面視窗**也在此（所有人可用） |
| **切斷** | 離開房間並重新載入（請先存檔） |

標有 `*` 的設定通常只影響你自己的瀏覽器，不會改到別人桌上的內容。

玩家可見的選單可由 GM 在「權限管理」調整（見 [權限管理](#permissions)）。預設對玩家開啟：圖片、音樂、工具箱、倉庫、筆記；預設關閉：地圖、預設場面、劇本文字。連線／聊天／戰鬥／設定／切斷永遠可見。

## 房間、身份與邀請連結 {#room}

### 大廳與建立房間 {#room-create}

1. 開啟網站後（尚未進房）會**自動顯示大廳**（一般視窗，畫面中央，不擋操作），並開啟 **連線** 面板。  
2. 設定暱稱、顏色、玩家圖示（會存在瀏覽器）。  
3. **大廳**：搜尋並加入別人開的房；也可「讀取房間」從本機資料夾備份恢復；關閉後可從連線面板再開。  
4. **建立房間**：房名；可設房間密碼；可設 **GM／玩家／訪客** 各身份為「開放／密碼／停用」。若**啟用中的身份皆設密碼**，會自動啟用 **V3 網路鎖（mesh-lock）**，連線頻道與身份密碼分離。

進入房間後，桌面物件、聊天、圖片等會在同房玩家間即時同步。  
若使用邀請連結進房，則不會再自動跳出大廳。  
連線面板（非訪客）可綁定資料夾備份、查看參加者；**GM 可踢出**參加者（對方會收到通知並重新載入）。  
有新版本時，連線面板會顯示 **PWA 更新**提示，確認後重新載入套用。

### 三種身份 {#room-roles}

| 身份 | 概要 |
|------|------|
| **GM** | 可看密語、卡背、未公開骰、角色／游標位置等；負責場景工具與多數房間管理 |
| **玩家（User）** | 一般參加；可編輯桌面（受房間規則與「我的角色」限制） |
| **訪客（Guest）** | 功能大幅受限：無法 ZIP／資料夾備份、多數編輯與快捷鍵；主要觀看與受限聊天 |

連線面板可「轉換身份」（需該身份開放，且必要時輸入密碼）。

### 邀請連結 {#room-invite}

在房間內可複製：

- 複製 GM 邀請  
- 複製玩家邀請  
- 複製訪客邀請  

取得連結的人可直接以該身份進房（連結可含角色密碼）。

> **注意**：不要把含密碼的邀請公開貼到任何人都能看的地方；直播時也請小心。

邀請失敗常見原因：房間已空（需有人在線）、密碼失效、該身份未開放、你已在別的房間。

### 私人連線 {#room-private}

可用對方 ID 做私人連線（非房間模式）。在房間內時無法使用私人連線。一人測試建議開兩個視窗。

## 存檔：ZIP 與本機資料夾備份 {#save}

兩種機制可並用。**空房不會留在伺服器**，存檔是延續戰役的唯一可靠方式。

| 比較 | **ZIP** | **資料夾備份** |
|------|---------|----------------|
| 時機 | 手動下載／讀取 | 綁定後自動覆寫（也可手動儲存） |
| 適合 | 帶走、分享、跨裝置帶檔 | 同機持續戰役、少手動 |
| 瀏覽器 | 多數桌面瀏覽器 | 建議 Chrome／Edge＋HTTPS |
| 訪客 | 不可用 | 不可用 |

入口：**連線** 面板或 **工具箱**（空白處右鍵精簡選單不含這些項）。

### ZIP（手動帶走） {#save-zip}

| 操作 | 說明 |
|------|------|
| **下載 ZIP** | 把當下整房打包成一個檔（含圖片等）；下載前會詢問**是否含音樂**，自行保管 |
| **讀取 ZIP** | 還原先前打包的狀態（**預設僅 GM**；可在權限管理開放給玩家） |

- 不會自動存；每次結束前請自己下載一次。  
- 建議：**先建房再讀取**，其他參加者才能一起同步；本機單人測試也可直接讀。  
- 按 **F5／Ctrl＋R** 重新整理時，系統可能詢問是否先下載 ZIP；已綁定資料夾時會先嘗試 flush 再重整（訪客略過）。  
- **密語不會進 ZIP**；換了連線 ID 後舊密語也可能看不到。
- **從資料夾讀取房間**同樣預設僅 GM（可開放給玩家）。

### 資料夾備份（自動覆寫） {#save-folder}

在桌面 Chrome／Edge（HTTPS）綁定本機資料夾後，依房間自動寫入備份。

**入口（非訪客）**

- **綁定／重新授權**資料夾（重新整理後可能需再授權一次；綁定時詢問是否含音樂）  
- **儲存房間**：立刻寫出  
- **讀取房間**：列出備份、可刪除；未進房可先建房再載入；**hover** 可更改／斷開備份資料夾  
- **個人設定***：可開關「備份／ZIP 含音樂」（自動備份套用此預設） 

#### 自動儲存規則 {#save-auto}

| 規則 | 說明 |
|------|------|
| Debounce 5 秒 | 變更後等 5 秒再寫 |
| 最短間隔 30 秒 | 遊玩中兩次成功寫入至少隔 30 秒 |
| 一房一檔 | `{roomId}.zip` + `{roomId}.meta.json`；同 roomId 覆寫 |
| 角色密碼 | 不以明文存放；用本機瀏覽器金鑰加密。換瀏覽器／裝置需重填 |
| 立即寫出 | 「儲存房間」、退出／換房、切訪客、登出、F5／Ctrl＋R、SW 更新重整前會 flush |
| 訪客 | 不可綁定、自動寫、手動存或從資料夾載入 |
| 進房不自動載入 | 即使本機有同 roomId 備份，加入線上房時**不會**覆寫 peer 桌面；載入一律手動 |

#### 還原語意 {#save-restore}

- **恢復房間**：沿用備份的 `roomId`（與名稱／開關／可解密時的密碼），之後自動備份覆寫同一檔。  
- 在**不同** roomId 的已連線房間載入：會以目前房間 ID 另存（fork）。  
- 載入進已連線房間：會覆寫桌面並同步給其他參加者——請先和團員確認。

## 地圖視角與基本操作 {#map-basics}

地圖預設是 **2.5D**：可平移、旋轉視角、縮放。地圖設定可改為 **2D 模式**（俯視相機＋角色／骰子平面繪製；筆記在 2D 下固定平放）。

### 視角 {#map-view}

| 操作 | 效果 |
|------|------|
| **Ctrl＋左鍵拖曳**／**右鍵拖曳** | 平移地圖 |
| **中鍵拖曳** | 旋轉視角 |
| **滾輪** | 縮放 |
| **Alt＋滾輪**（無選取） | 左右旋轉視角約 3° |
| **Alt＋Shift＋滾輪**（無選取） | 俯仰旋轉視角約 3° |
| **Shift＋滾輪** | 左右移動畫面 |
| **Ctrl＋滾輪** | 上下移動畫面 |

工具箱或**設定**選單可「視點重置」（預設／俯視）。清空桌面視窗亦同（僅桌面版；所有人可用，不依賴工具箱權限）。

想搭城市微縮感（天台、斜天橋、招牌）見 [微縮城市搭景](#miniature-city)。

### 物件 {#map-objects}

| 操作 | 效果 |
|------|------|
| **左鍵拖曳** | 移動物件 |
| **拖旋轉把手** | 轉向 |
| **右鍵** | 該物件選單（翻面、抽牌、擲骰、切換圖像等多在此） |
| **雙擊** | 開啟詳情／設定 |
| **Alt＋雙擊** | 遮罩：觸發已勾選動作（見 [遮罩動作](#mask-actions)） |

空白處右鍵為精簡選單；新增項目收進一級 **「新增物件」**（角色、遮罩、地形、筆記、卡牌、骰子、射程，以及光源／牆壁／繪圖等，依權限）。

圖片、音樂可直接拖進瀏覽器。筆記媒體也可拖到筆記倉庫或設定。

## 選取、鍵盤快捷鍵、路徑移動、Ping {#controls}

完整一覽見 [附錄：快捷鍵速查](#hotkeys)。訪客多數編輯快捷鍵不可用。

### 選取 {#select}

| 操作 | 效果 |
|------|------|
| 左鍵點物件 | 選取（高亮） |
| 左鍵空白拖曳 | 框選 |
| Shift＋點 | 加入／移出多選 |
| Shift＋拖曳 | 加選框選 |
| 點空白／Esc | 取消選取 |

> **注意**：**Ctrl＋左鍵**是平移或路徑路點，**不是**多選。

### 鍵盤（需先選取） {#keyboard}

| 按鍵 | 效果 |
|------|------|
| **WASD／方向鍵** | 移動（可對角） |
| **Shift＋WASD** | 改變面向 |
| **Delete** | 刪除（角色進回收區） |
| **Ctrl＋C／X／V** | 複製／剪下／貼上（貼在滑鼠游標處；選取文字時仍可複製文字） |
| **Ctrl＋Shift＋V** | 貼上為暫存 Token（僅剪貼簿含角色／Token 時；獨立表、不進倉庫） |
| **Ctrl＋Z** | 復原 |
| **Ctrl＋Y** 或 **Ctrl＋Shift＋Z** | 重做 |
| **[** / **]** | 送到後層／前層 |
| **Alt＋滾輪** | 旋轉面向約 3°（有選取時） |
| **Alt＋Shift＋滾輪** | 旋轉立繪傾角（roll）約 3°（有選取時） |
| **Ctrl＋Shift＋滾輪** | 旋轉約 45° |
| 拖曳放開時按住 **Shift** | 暫時不吸附格線 |
| **Esc** | 取消選取（路徑草稿中則取消路徑）；無選取時關閉最前可關視窗（先關右鍵選單／對話框） |
| **Ctrl＋Shift＋D** | 開關右上角 **DEBUG pose**（顯示視角角度／座標與選取物件的 rotate／roll／高度等；預設關閉，僅本機） |

**復原／重做範圍（本機堆疊）**：移動、旋轉、刪除、剪下貼上、圖層、路徑移動；場景工具的建立／刪除／微移。  
輸入框內的 Ctrl＋Z 仍由瀏覽器處理文字，不會動到桌面 undo。

### 浮動預覽（Hover） {#overview-pin}

滑鼠停在 Token／物件上會出現**浮動預覽卡**。左上角 **釘選（push_pin）**：釘住後移開滑鼠也不會關；再點一次取消。物件刪除／進回收區時對應預覽會關閉。移開後約 0.5 秒再淡出關閉（未釘選時）。

### 路徑移動 {#path-move}

一次只對**單一 Token**（多選時只動最先選取的那個）：

1. 選取 Token。  
2. **Ctrl＋左鍵**加路點（可放開 Ctrl，路點仍保留）。  
3. **左鍵**點終點開始移動，**或**按 **Space** 以目前路點出發。  
4. **右鍵**＝取消最後一個路點；**Esc**＝取消整條路徑。  

路徑移動中地圖下方會顯示簡短 HUD 提示。路徑移動可被 Ctrl＋Z 復原。

### Ping {#ping}

| 操作 | 效果 |
|------|------|
| 地圖空白處**長按**約 1 秒 | 一般標記 |
| **Shift＋長按** | 警告標記 |

用於提醒所有人注意某個位置。

### 微縮城市搭景：天台、斜天橋、招牌 {#miniature-city}

本站是 **CSS 2.5D 虛擬桌面**，不是 WebGL 城市引擎。微縮感靠透視相機、地形盒、高度、斜坡與貼圖語彙組合出來——沒有「招牌／天橋／天台」專用物件，一律用 **地形（Terrain）配方** 拼。

#### 整體微縮感（相機與層次）

- 維持 **3D 視角**（勿開 2D 模式）；略抬俯仰、略拉遠，讓盒子像桌上模型。  
- 用 **2～4 個高度帶**（地面／低層簷／天台／高架），不要連續亂高。  
- 開 **落影**（地形／物件高度 > 0 時陰影會「浮」起來），這是微縮感的關鍵信號。  
- 地圖底圖用 **俯視城市平面**（屋頂、馬路、天橋投影）；立體地形只補「會擋視線／可站上去」的結構。

#### 天台感（大廈 → 可站的屋頂）

1. 一塊較高的地形 = 樓體：`height` 大、牆面貼「樓層／外牆」、頂面貼「屋頂／天台」。  
2. 天台活動層：再放一層 **薄高度、略小一點的頂面地形**（或遮罩）在 `altitude` 對齊樓頂，貼天台材質（地磚、欄杆陰影、水塔、冷氣機俯視）。  
3. 角色調到同一高度，站在「天台」上（可互動地板會托住腳跟）。  
4. 牆面貼圖做成 **側視外牆**，頂面做成 **俯視天台**——同一棟樓兩種語彙，天台感立刻成立。

避免：整棟只用一張側視圖當頂面（會像立牌，不像屋頂）。

#### 斜角天橋（行人／馬路天橋）

用 **斜坡地形**，不要硬用水平長條假裝斜橋：

| 參數 | 建議 |
|------|------|
| `width` | 窄（1～2 格）當橋面寬 |
| `depth` | 跨距（連接兩棟的距離） |
| 斜度 | 地形設定可直接輸入 **坡度（度）**（約 1～45°）；會依跨距重算 `height` |
| `slopeDirection` | 對準上坡方向（上／下／左／右） |
| `altitude` | 整段抬到樓與樓之間的空中高度 |
| 牆面 | 可關或極矮，避免像實心坡道；頂面貼「橋面／欄杆俯視」 |

進階：

- **兩段式**：水平高架（普通地形）＋兩端短斜坡接樓頂／馬路。  
- **斜向天橋**：先把地形旋轉成對角，再選對應斜坡方向；貼圖用透視校正過的橋面。  
- **橋下空間**：橋本體抬 `altitude`，底下仍可見底圖馬路／另一層地形，才有「跨街天橋」而非「填滿坡」。  
- **步行**：角色用 WASD／路徑／拖曳走上斜面時，腳會跟斜面高度；底座會貼齊斜面（本機視覺）。離開橋面回到地面。

#### 斜角招牌（薄地形配方）

招牌也是地形，不是新物件類型：

1. **薄盒**：寬／深／高可小到約 `0.1` 格；厚度決定「牌匾」立體感。  
2. **分面貼圖**：設定裡可為底面、南／北／東／西牆各指定圖（未設則回退到預設牆／地板）。招牌正面常用南牆。  
3. **關掉鏡像**（必要時）：關閉「上／左牆鏡像」，避免霓虹字被翻轉。  
4. **霓虹**：選 soft／tube／edge／flicker／pulse／strobe，並設顏色；可只打在牆或地板。  
5. **裝飾招牌請關閉「可互動」**（`isInteract`）：否則薄牌會被當成可走斜面／天台，角色腳會「踩」上去。

也可把 **STL／OBJ／glTF** 拖到桌面，選「地形（模型烘焙）」：會估尺寸並自動烘六面貼圖（STL 無色為灰階浮雕；OBJ／glTF 可帶材質色）。仍是普通地形，不是常駐 3D 模型。

仍無「貼牆錨點」的懸臂招牌；用高度＋位置近似即可。

#### 貼圖與氛圍

- **一物多圖**：牆 = 側視；頂／底 = 俯視；招牌四面可各不相同。  
- 尺度：窗戶、欄杆、招牌字在貼圖裡偏「略大一點」，微縮模型感更強。  
- 燈光：傍晚用偏暖點光打在招牌／天台邊緣；黑暗略開，讓盒子剪影更立體（見 [場景工具](#scene-tools)、[地圖氣氛](#map-weather)）。  
- **預設場面**：把相機角度＋天氣＋燈光存成「城市夜景」，方便重現。

#### 常見失敗

| 狀況 | 原因／解法 |
|------|------------|
| 屋頂像立牌 | 頂面誤用側視外牆圖 → 改俯視天台材質 |
| 天橋像填土坡 | 沒抬 `altitude`，或牆面全開 → 抬高並隱藏牆面 |
| 微縮感消失 | 開了 **2D 模式** → 改回 3D 視角 |
| 高度帶混亂 | 高度值亂跳 → 收成 2～4 帶（地面／簷／天台／高架） |
| 角色踩上招牌 | 招牌仍開著「可互動」→ 關掉 |
| 招牌字鏡像 | 關「上／左牆鏡像」 |

#### 功能對照（簡表）

| 目標 | 現況 |
|------|------|
| 斜角天橋 | 地形斜坡＋坡度（度）＋`rotate`；可隱藏牆面 |
| 在天橋上步行 | 腳跟斜面高度；底座貼齊斜面（本機） |
| 天台層 | 地形高度／altitude 堆疊；可互動地板托腳 |
| 霓虹招牌 | 薄地形＋分面貼圖＋霓虹類型／顏色；裝飾關可互動 |
| 貼牆懸臂招牌 | 仍無錨點；高度＋位置近似 |
| 地形牆面本身傾斜 | 牆面固定垂直；斜的是頂面 |

## 場景工具（燈光／牆／繪圖） {#scene-tools}

| 操作 | 說明 |
|------|------|

| Delete | 刪除 |
| Ctrl＋Z／Y | 復原／重做 |
| Enter／雙擊 | 完成牆、多邊形等 |
| Esc | 取消當前繪製 |

房間可由 GM 設定是否允許玩家使用部分場景工具。

## 預設場面與劇本文字 {#scene-preset-scenario}

### 預設場面 {#scene-preset}

**預設場面**（訪客不可用）用來儲存目前桌面狀態，之後一鍵切回：

| 會記住 | 說明 |
|--------|------|
| Token／物件位置 | 該地圖上的角色、卡、骰、筆記、範圍等姿態（支援**多地圖 placement**：同一物件可出現在多張地圖） |
| 桌面氣氛 | 黑暗、天氣、燈光、牆、遮罩、繪圖等 |
| 多軌 BGM | 與音樂面板的曲目快照一致 |
| （可選）切場文字 | 套用時送到聊天 |
| 縮圖預覽 | 儲存時擷取地圖預覽 JPEG，列表顯示縮圖 |

操作要點：

1. 左側選單打開 **預設場面** →「儲存目前場面」（地圖設定裡也有同名按鈕）。  
2. 移動棋子／改氣氛後，再按「套用」應還原到儲存時的位置與氣氛；「**套用（保留棋子）**」則只還原氣氛／BGM，保留目前 Token 姿態。  
3. 「覆寫場面快照」更新內容；「重新綁定目前桌面」只改綁定的地圖。  
4. 人物倉庫依**目前檢視地圖**綁定顯示；Ctrl＋拖曳角色可產生**暫存複本**（不進回收區）。  
5. 讀取房間後若場面顯示異常，請再覆寫一次快照（新存檔會帶穩定物件 ID）。  

引導教學第二章會請你實際打開此面板一次。

### 劇本文字 {#scenario-text}

**劇本文字**（訪客不可用）用來準備旁白／劇本，並送到**目前聊天視窗所選的分頁**：

- 可選發言名稱：條目標題／角色／玩家。  
- 「送出」送全文；選取一段文字後可「送出選取」。  
- 以**角色**發言且內文含「」時，會觸發**浮動式對話框**（與一般聊天相同）。  
- 聊天視窗可多開，方便一邊看劇本一邊看骰／密語。  

引導教學第二章同樣會帶你打開此面板。

## 戰鬥輪 {#combat}

打開 **戰鬥**：

1. （可選）新增多組戰鬥名稱。  
2. 桌面選取角色 → **加入選取**，或 **加入桌面全部**。也可角色右鍵「加入戰鬥」。  
3. 設定先攻骰、是否追蹤資源、是否「跳過敗北」。  
4. **全部擲先攻**／NPC 擲先攻／使用資源先攻／手動改先攻。  
5. **開始戰鬥** → 用回合⟶／輪⟹ 推進；有人可按「結束我的回合」。  
6. 可標記敗北、隱藏對玩家顯示、對焦棋子、結束戰鬥。  

**死亡**狀態與戰鬥「倒下／敗北」會**雙向同步**（見 [狀態](#status)）。  
空清單時介面會提示：先選取再加入，再擲先攻並開始。

## 狀態、光環、套圈、圖片效果、死亡 {#status}

角色右鍵相關：

### 狀態 {#status-list}

目盲、迷惑、耳聾、恐慌、被擒、乏力、隱形、麻痺、石化、中毒、倒地、束縛、震懾、昏迷、力竭、**死亡** 等。  
狀態圖示常駐於名牌；tip 顯示名稱與等級。

### 光環／套圈 {#aura}

- **光環**：角色周圍氛圍特效。  
- **套圈**：火環、魔法陣、科技環、邪異環、聖光環等（底盤）。

### 圖片效果（Image FX） {#image-fx}

可套用於棋子／立繪／聊天圖示／角色卡等（依選單）：

- 水平／垂直翻轉、模糊  
- 灰階、復古（sepia）、高對比  
- 黑／白剪影  
- **Matrix**（數字・字母流動）  

可用來表示變身、中咒、死亡灰階等。

## 圖片、音樂、工具箱、Cut-in {#media}

### 圖片 {#media-image}

共用圖庫：上傳角色圖、地圖等。也可拖曳檔案進瀏覽器。注意隱藏圖片與劇透。

### 音樂 {#media-music}

**音樂**面板支援**多軌**房間 BGM／環境音（最多約 4 軌並行）：可調房間曲目音量與本機環境音；試聽僅本機、不廣播。  
每個音訊檔最大 **20MB**。  
曲庫可依**資料夾**整理：各資料夾旁可加連結／上傳；從電腦拖檔時會高亮目標資料夾。支援多選拖曳搬移與 **Delete** 刪除。  
**下載 ZIP／資料夾備份可選擇是否包含已上傳音樂**（檔案可能很大）；略過時仍保存曲庫結構。讀取含音樂的 ZIP 後可還原。  
切場面時可用 [預設場面](#scene-preset) 一併還原曲目快照。

### 工具箱速查 {#toolbox}

- 天氣、日夜  
- 播放 Cut-in（全員或指定玩家）  
- Cut-in 設定、骰表設定  
- 視點重置、清空桌面視窗（**所有人可用**；亦在設定／更多選單）  
- 公開全部骰子／硬幣  
- 下載／讀取 ZIP、資料夾備份  

空白處右鍵為精簡選單：有工具箱權限時含天氣等；無工具箱權限時仍可新增物件，以及視點重置／清空視窗。地圖設定項需有「桌面地圖」選單權限。

### Cut-in {#cutin}

可設定圖片或 YouTube 等演出，在關鍵時刻對全員或指定 peer 播放。可調位置、尺寸、是否擋在立繪前等。

## 訪客模式與權限 {#guest}

### 訪客限制（摘要） {#guest-limits}

無法：ZIP 下載／讀取、資料夾備份、編輯筆記、圖片／音樂庫編輯、地圖／工具箱多數編輯、預設場面、劇本文字、多數編輯快捷鍵。  
主要可：觀看、受限聊天。

開房時可為 Guest 設開放／密碼／停用；仍支援舊版「允許訪客」概念。  
即使有邀請連結，房間若停用該身份仍進不去。

### 權限管理 {#permissions}

GM 可在**連線**面板開啟「權限管理」（僅 GM）。可調整：

| 類別 | 說明 |
|------|------|
| **讀取房間資料** | 讀取 ZIP／從資料夾載入房間；**預設僅 GM** |
| **選單可見** | 玩家左側選單項目；**預設開**：圖片、音樂、工具箱、倉庫、筆記；**預設關**：地圖、預設場面、劇本文字。連線／聊天／戰鬥／設定／切斷永遠可見 |
| **場景工具** | 燈光／牆／繪圖等建立與修改是否開放給玩家 |

訪客不受上述選單勾選影響（訪客另有固定限制）。

## 本機設定 {#local-settings}

**設定\***（只影響本機）：

- 格線顯示、吸附  
- 新訊息提示音  
- 訊息一律靠左顯示  
- **無聊天視窗時有人發言則自動開啟**（預設關；開啟後，聊天窗已關且有人發言時會自動彈出）  
- 顯示角色資源 HUD  
- 各面板大小／位置會記住（本機）；桌面可「重排面板」  
- 滑過教學提示（**僅桌面**；手機／平板不顯示）  
- 顯示立繪、名稱標籤、立繪自動退場、清除立繪  
- 介面語言  
- 重新引導教學、滑過顯示教學、操作說明  

這些不會改寫別人桌上的地圖或角色資料。  
聊天視窗的**大小與位置**也會記在本機（拖曳／縮放後自動保存）。

## 建議流程（開團 checklist） {#checklist}

### GM 開新團 {#checklist-gm}

1. Chrome 開啟 https://z01.hktrpg.com/  
2. 連線 → 設暱稱 → **綁定資料夾備份**（建議）→ 建立房間（設好 GM／玩家／訪客規則）  
3. 複製各身份**邀請連結**私訊給團員  
4. 地圖：上傳地圖圖、調格線；需要時開黑暗／天氣／視野  
5. 圖片庫上傳 Token；右鍵放角色；設視野／我的角色  
6. 需要戰鬥時開戰鬥輪；需要迷宮時用場景工具畫牆與燈  
7. （可選）預設場面、劇本文字、筆記 handout  
8. （可選）遮罩設好 Alt＋雙擊動作  
9. 結束前：確認資料夾已寫入，或再下載一份 ZIP  

### 玩家加入 {#checklist-player}

1. 用邀請連結或大廳進房  
2. 設暱稱；認領「我的角色」／視野角色  
3. 聊天選好 BCDice 規則；需要時開聊天面板  
4. 不要依賴「下次還在線上」——重要進度請催 GM 存檔  

### 下次續攤 {#checklist-resume}

1. GM 進站 → 建房或從資料夾「恢復房間」（同 roomId）→ 或讀取 ZIP  
2. 再發邀請；確認大家進的是同一房  
3. 若從資料夾恢復後密碼提示需重填，把角色密碼再存一次即可

## 常見問題 {#faq}

**Q. 為什麼大廳找不到昨天的房？**  
A. 空房會消失。請用 ZIP 或資料夾備份恢復。

**Q. 資料夾備份換電腦後密碼沒了？**  
A. 密碼用本機瀏覽器金鑰加密，換機／換瀏覽器需重填；填完再存一次即可。

**Q. 為什麼我拖不動別人的角色？**  
A. 對方可能已設「作為我的角色」；或你是訪客；或權限不足。

**Q. 開了視野一片黑？**  
A. 請到角色倉庫右鍵自己的 Token → 設視野／亮光，並勾「作為我的視野角色」。GM 應不受限。

**Q. Ctrl＋左鍵變成路徑不是平移？**  
A. 已選取 Token 時，Ctrl＋左鍵會加路點。取消選取後再 Ctrl＋拖曳即可平移。

**Q. 復原沒反應？**  
A. 焦點是否在輸入框（此時 Ctrl＋Z 改文字）？是否訪客？該操作是否不在 undo 範圍？

**Q. 密語讀 ZIP 後不見？**  
A. 設計如此：密語不進 ZIP。請勿只靠 ZIP 保存密語內容。

**Q. 手機能用嗎？**  
A. 基本觀看可能可以，但鍵盤操作、資料夾備份、精細場景編輯等以桌面 Chrome 為準。

**Q. 連線一直失敗？**  
A. 檢查網路、防火牆、是否 HTTPS、後端是否正常。同房可看連線面板的連線狀態（良好／不良）。

**Q. 重新整理後資料夾備份失效？**  
A. 瀏覽器可能要求重新授權目錄。到連線面板按「綁定／重新授權」即可。

**Q. 筆記「僅自己可見」後自己也看不到？**  
A. 重開網頁後連線 ID 常會變（同角色隱身）。取消勾選再開一次，或請 GM 協助。

**Q. 雙擊遮罩沒反應／一直開設定？**  
A. 動作是 **Alt＋雙擊**。一般雙擊＝開設定。請先在設定勾選動作。

**Q. 讀取備份後別人桌面被蓋掉？**  
A. 載入進已連線房間會覆寫並同步給所有人。請先和團員確認，或先空房再恢復。

**Q. 套用預設場面後棋子沒回到原位／場面顯示地圖已刪？**  
A. 請「覆寫場面快照」再存一次（舊快照可能缺穩定物件 ID）。讀房後若綁定錯亂，可用「重新綁定目前桌面」或再覆寫。

**Q. 劇本文字送到哪個聊天分頁？**  
A. 送到**目前開啟的聊天視窗**裡所選的那個分頁；聊天視窗可多開。

**Q. 劇本文字用角色發言為什麼沒有浮動對話框？**  
A. 需以「角色」發言名稱送出，且內文含「」；該聊天標籤也需啟用浮動對話／立繪相關選項。

**Q. 關掉聊天後有人說話為什麼不會自動跳出來？**  
A. 到 **設定\*** 開啟「無聊天視窗時有人發言則自動開啟」（預設關閉）。

**Q. 多地圖時別人轉棋子，我這張圖的棋子也轉了？**  
A. 2026/08/11 起各圖姿態獨立。請確認雙方都已更新到新版並硬刷新；舊房物件若只有單圖 placement，行為與單地圖相同。

**Q. 筆記翻面後畫面空白？**  
A. 無背面圖時會鏡像正面（不應空白）。若仍空白請硬刷新；有背面圖時翻面應顯示背面圖。

## 附錄：快捷鍵速查 {#hotkeys}

訪客多數編輯快捷鍵不可用。焦點在輸入框時，Ctrl＋Z／C／V 等由瀏覽器處理文字。

| 操作 | 效果 |
|------|------|

| 中鍵拖曳 | 旋轉視角 |
| 滾輪 | 縮放 |
| Alt＋滾輪（無選取） | 左右旋轉視角約 3° |

| Shift＋滾輪 | 左右移動畫面 |
| Ctrl＋滾輪 | 上下移動畫面 |

| 操作 | 效果 |
|------|------|
| WASD／方向鍵 | 移動 |
| Shift＋WASD | 面向 |
| Delete | 刪除（角色→回收區） |
| Ctrl＋C／X／V | 複製／剪下／貼上（貼在游標處；系統剪貼簿若為 CCFOLIA 角色 JSON 則匯入 Token） |

| [ / ] | 後層／前層 |
| Alt＋滾輪 | 旋轉面向約 3°（有選取時） |
| Alt＋Shift＋滾輪 | 旋轉立繪傾角（roll）約 3°（有選取時） |
